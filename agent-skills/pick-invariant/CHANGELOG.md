# Changelog

## 11.1.0

- Compressed the always-loaded kernel without changing v11.0 theorem architecture, authority modes,
  adaptive-depth semantics, specialist triggers, lazy-reference routing, or presentation policy.
- Promoted context efficiency from a soft v11.0 metric to a **hard Pareto dimension relative to
  v11.0**; savings may not come from weakening or suppressing an activation.
- Added a frozen v11.0 activation oracle and an 88-case exact-equivalence suite: 52 release fixtures
  plus 36 boundary fire/do-not-fire cases.
- Added mutation-sensitivity checks covering mode, depth, all protected gates, and reference sets.
- Kept the embedded default prompt and behavioral references byte-identical to v11.0; only the kernel
  and release-evaluation contract/docs change behaviorally relevant text.
- Added hard context-path matrices using transparent word/character/byte proxies and a 50,000-run
  positive context-cost sensitivity simulation; no behavioral score bonus is assigned for compression.
- Added migration guidance and acceptance tests for activation invariance and hard token/context Pareto.

## 11.0.0

- Kept Pick's Theorem as the dominant structural grammar while adding an explicit target-relative
  decision-preserving quotient criterion for retention/compression.
- Added `references/decision_quotients.md` with Myhill-Nerode/bisimulation-inspired safe merging,
  continuation-sensitive equivalence, deletion+merge minimality, Blackwell-style channel comparison,
  and authorized Le Cam-style approximate sufficiency.
- Extended probability semantics with observation-channel separation, null-event conditioning /
  disintegration safeguards, and Haar-style canonical-relative invariant-measure discipline.
- Added valuation/Ehrhart composition gates, local/global obstruction handling, ordinal value-of-
  information observation selection, and CEGAR-style real/spurious counterexample refinement.
- Added a presentation firewall: theorem machinery is internal control logic by default; routine
  answers use native-domain language and embedded prompts state governing principles rather than
  theorem names.
- Added decision-quotient, composition, and refinement templates plus v11 acceptance tests 186–225.
- Rebuilt the release evaluation around 52 fixtures (29 inherited + 23 v11 extensions), theorem
  ablations, a Nerode-dominant architecture neighbor, an always-on ceremonial control, and 50,000
  sensitivity perturbations.
- Added an exact elementwise behavioral Pareto gate relative to the declared matrix: protected
  capabilities, fixture quality, synthetic fixture cost, and maintainability must all be non-
  regressing with at least one strict improvement over v10.1.
- Changed context/token efficiency to an explicit best-effort soft metric for v11 because the kernel
  is intentionally larger; detailed specialist theory remains lazy-loaded.

## 10.1.0

- Refactored v10 probability doctrine behind a mandatory materiality-triggered lazy-load boundary.
- Reduced the always-loaded kernel while preserving v10 measure, transport, quotient, conditioning,
  canonicality, underdetermination, and distributional-sufficiency semantics in the probability
  reference.
- Tightened `PROBABILITY_MEASURE_TRIGGER`: stochastic vocabulary alone is insufficient; the law or
  sampling semantics must be able to materially change the requested target.
- Added explicit degradation when the triggered probability reference cannot be loaded.
- Added regression tests preventing heavy probability doctrine from drifting back into `SKILL.md`.
- Added a measured context-cost report; T1 semantic scoring keeps the v10.1 profile identical to v10
  rather than granting an artificial cheaper reasoning profile.

## 10.0.0

  `CANONICAL_RELATIVE_TO(G)` claims.
- Added quotient/multiplicity, Jacobian/fiber, conditioning/renormalization, and mathematical-vs-

- Added `DECISION_SUFFICIENT` versus `DISTRIBUTION_SUFFICIENT` and semantic underdetermination

- Expanded the generic deterministic evaluation with stochastic measure failure families and
