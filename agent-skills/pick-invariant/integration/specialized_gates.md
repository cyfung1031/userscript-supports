# Specialized Gates and Mature-Owner Integration

These gates are **conditional refiners**, not default stages. They preserve Pick as the dominant
structural grammar while preventing overloading the kernel with specialist doctrine.

## 1. Mature owner gate

A validated specialized procedure owns its domain. Its native verdict normally becomes a reusable
`I` fact in a larger composition; PickInvariant does not regenerate it.

Escalate only when:

- applicability/authority is unresolved (`P`);
- output crosses an uncovered semantic seam (`B`);
- multiple locally valid results interact through non-local structure (`χ`);
- an accepted procedure gap is explicitly adopted.

A mature owner's verdict remains visible; optional Pick annotations never erase native semantics.

## 2. Decision-quotient gate

Trigger when two distinct states/representations are proposed to be treated as equivalent, when a
minimality/compression claim is made, or when a state-machine continuation may distinguish apparently
equal snapshots.

Load `references/decision_quotients.md`.

Do not trigger merely because two raw states differ.

## 3. Probability/Blackwell gate

Trigger when probability law, sampling protocol, quotient weighting, conditioning, stochastic
transport, or observation-channel information can change the target.

Load `references/probability_semantics.md`, and the decision-quotient reference when comparing
stochastic information sufficiency.

## 4. Null-conditioning / Borel-style gate

Trigger only when conditioning is on a zero/null-measure event or a lower-dimensional event whose
conditional law depends on limiting/parameterization semantics.

Require an explicit regular-conditional/disintegration/limiting basis. Do not impose this gate on
ordinary positive-probability conditioning.

## 5. Symmetry / Haar-style gate

Trigger when a claim of invariant or canonical probability measure is justified by a transformation
group. Require the object space, group action, invariance, relevant uniqueness, and normalization.

The permitted conclusion is normally `CANONICAL_RELATIVE_TO(G)`.

## 6. Composition / valuation gate

Trigger when a global target is reconstructed by combining overlapping pieces, repeated partitions,
or local summaries.

Load `references/composition_and_refinement.md` and classify the composition as `VALUATIVE`,
`CONSERVATIVE_MERGE`, `ORDER_SENSITIVE`, `TOPOLOGY_SENSITIVE`, `NONCOMPOSABLE`, or `UNKNOWN`.

Do not infer additive composition from the Pick metaphor.

## 7. Ehrhart gate

Trigger only for genuine lattice-polytope lattice-point counting under integer dilation (or another
domain where the relevant theorem's assumptions are independently established). This is an extension
of the literal mathematical family, not generic process scaling.

## 8. Observation-value gate

Trigger when more than one observation/test could resolve the leading uncertainty and acquisition
cost/risk matters. Prefer the cheapest reachable discriminator that can change the decision.

Use ordinal reasoning unless a legitimate prior/loss/utility model is supplied.

## 9. CEGAR-style abstraction-refinement gate

Trigger when a failed contrast/counterexample may arise because the compiled abstraction is too
coarse.

```text
counterexample
-> validate against raw/admissible semantics
-> REAL: gap/failure evidence
-> SPURIOUS: smallest witness-backed representation refinement
-> rerun failed contrast + relevant regressions
```

A verifier failure is not automatically a procedure failure.

## 10. Local/global obstruction / sheaf-style gate

Trigger only when local facts and pairwise overlap restrictions are all individually compatible yet
a global object/decision may fail to exist.

Represent local facts, overlap restrictions, and the gluing obstruction. Avoid sheaf terminology in
ordinary output unless it helps the user.

## 11. Example: locally valid owners, invalid global composition

```text
Owner A -> local PASS
Owner B -> local PASS
Owner C -> local PASS
pairwise seams -> PASS
                 |
                 v
global cycle / duplicate ownership / incompatible gluing
                 |
                 v
χ or composition obstruction -> global decision differs
```

The local native verdicts remain correct. The gap is in composition, not in their interior semantics.

## 12. Presentation rule

Specialized gates are internal controls. Once they identify the material domain distinction, express
the result in native language and omit theorem names/certificates unless requested or explanatory.
