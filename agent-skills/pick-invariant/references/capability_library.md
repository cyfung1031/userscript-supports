# Lazy Structural Capability Library

Load only when the target or certified gap requires the capability. The list is a toolbox, not a
mandatory pipeline.

## Domain/precondition probe (`P`)
Check authority, scope, observability, freshness, schema, version, exclusions, and other conditions
governing applicability.

## Interior extractor (`I`)
Reuse validated local-owner semantics and identify the smallest locally meaningful facts needed by
the target.

## Boundary reconciler (`B`)
Compare producer guarantees with consumer requirements; preserve caveats, identity, freshness, units,
authority, and transformation semantics.

## Topology probe (`χ`)
Test cycles, overlap, disconnected components, omitted regions, ordering, reachability, shared
ownership, and conservation only when local + seam reconstruction is insufficient.

## Reconstruction checker
Test whether `D` factors through the compiled representation for the certified domain.

## Decision-quotient checker
Given candidate distinctions/classes, test whether removal or merging collapses an admissible
acceptance-changing contrast. For process targets, include future continuations only when material.

## Stochastic-information comparator
When the target depends on an observation channel, test decision equivalence, dominance, or
incomparability. Use approximate sufficiency only with an authorized tolerance/loss model.

## Contrast generator
Construct minimal admissible state pairs or continuations that differ in one suspected distinction
and could require different decisions.

## Contrast ledger
Retain materially tested pairs, admissibility/oracle evidence, quotient disposition, and outcomes
without automatically enlarging the compiled representation.

## Lineage/history-erasure probe
Construct different admissible histories with equal current observables and test whether authoritative
target decisions differ.

## Projected-trace probe
Compare only contract-relevant events when ordering or side effects can change the target even if
final values match.

## Irrecoverability checker
Determine whether any authorized current observable can separate a certified collapsed contrast; if
none can, require an escape or prospective encoding rather than an invented decoder.

## Composition classifier
When local pieces are combined, classify the rule as valuative, conservative merge, order-sensitive,
topology-sensitive, noncomposable, or unknown. Do not infer additivity from Pick structure.

## Local/global obstruction probe
When local and pairwise compatibility pass but no global state may exist, inspect the smallest gluing
or global-consistency witness.

## Observation-value selector
Rank reachable tests by operational cost/risk and target-separating power. Prefer the cheapest
sufficient discriminator; keep the ranking ordinal unless legitimate probabilities/utilities exist.

## Counterexample validator / abstraction refiner
Classify a failed contrast as real, spurious, or unknown against raw/admissible semantics. For a
spurious witness, refine only the smallest erased distinction and rerun the failed contrast.

## Independent reconstruction
Derive the target from the compiled representation through a second reasoning path to detect hidden
dependence on raw state.

## Residual diagnosis
Given a real collapsed contrast, classify the missing distinction as `P`, `I`, `B`, or `χ`.

## Incremental invariant tracker
Update only changed compiled predicates/classes during execution; do not recompute unrelated
semantics.

## Procedure minimizer
After sufficiency, attempt deletion and class-merge reductions.

## Promotion analyzer
Detect recurring stable representations/quotients suitable for direct procedure ownership.
