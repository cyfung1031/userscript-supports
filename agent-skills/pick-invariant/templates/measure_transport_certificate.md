# Measure Transport Certificate

Use when a producer distribution is mapped to a consumer object space.

```text
analysis_phase: PICK_EXPLORE | PICK_AUDIT | PICK_DERIVE
certificate_issuer:
adoption_authority:
oracle_or_authority:
source_space_and_measure:
mapping_F:
target_object_space:
pushforward_measure_F_star_nu:
many_to_one_or_fiber_structure:
jacobian_or_change_of_variables:
quotient_multiplicity:
mathematical_condition:
conditioning_semantics: POSITIVE_MEASURE_EVENT | REGULAR_CONDITIONAL | DISINTEGRATION | LIMITING_CONSTRUCTION | UNSPECIFIED
condition_event:
pre_condition_law:
post_condition_law:
acceptance_probability:
zero_or_near_zero_behavior:
numeric_guard:
selection_or_rejection:
renormalization:
target_event_or_law:
evidence_and_verifier:
claim_level: DECISION_SUFFICIENT | EPSILON_DECISION_SUFFICIENT | DISTRIBUTION_SUFFICIENT
forbidden_outputs_without_adoption: adopted_measure | canonicality | procedure_gap | mutation
```

If the map is nonlinear, many-to-one, projected, quotiented, or rejection-conditioned, the
corresponding fields cannot be omitted; missing values produce an explicit escape or
`INSUFFICIENT_EVIDENCE`.
